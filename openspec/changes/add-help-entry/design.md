# Design

## Context

关于页位于 `lib/src/features/mine/about_update_dialog.dart`，已有 `_link` 负责链接行展示，`_openLink` 通过注入的 `openLink` 打开地址，并处理返回 `false` 和异常两种失败。默认打开行为来自 `external_links.dart`，使用系统外部应用。

现有关于页测试能注入链接回调，并覆盖小窗口、大字体和多个平台的更新行为。本次设计仅明确帮助目的地、复用路径和失败处理，不引入新的页面状态或导航结构；动机见 `proposal.md`，行为要求见 `specs/about-help/spec.md`。

## Goals / Non-Goals

**Goals:**

- 让帮助入口沿用关于页的布局、语言和交互方式。
- 集中维护帮助地址，并通过现有可注入回调验证实际请求的目标及失败反馈。

**Non-Goals:**

- 不新增内嵌浏览器、帮助中心页面、在线内容接口或外部依赖。
- 不调整音频会话、播放状态、后台行为、更新下载和版本号。

## Decisions

1. **默认使用本仓库 README 作为帮助目的地。** 当前 README 已包含“开始使用”和客户端下载说明，能够与实际客户端维护在同一仓库。暂不新增尚未确定内容和路由的独立帮助站；如果需要更换目标，应先同步修订本变更的提案、规格和任务。
2. **在 `external_links.dart` 集中声明帮助地址。** 沿用现有仓库常量构造地址，避免在页面和测试中散落独立字符串。无需新增设置项或配置接口。
3. **通过现有 `_link` 和 `_openLink` 接入。** 放在关于页链接卡片内，建议位于“项目仓库”之前，采用帮助图标、“使用帮助 / Help”标题和用途说明。文案继续使用该页面现有的 `context.localeText`，无需为本次小改动重构本地化体系。
4. **复用外部打开和错误处理。** 返回 `false` 时显示无法打开链接的提示；抛出异常时沿用现有错误消息转换，不新增重试状态。新测试通过已有 `openLink` 注入覆盖成功与失败，不启动真实浏览器。

## Risks / Trade-offs

- 外部 README 依赖网络与浏览器可用性，且当前文档以中文为主 → 标题和说明提供中英文，帮助正文沿用现有文档；打开失败时明确反馈。外部应用接受请求不等于网页内容已成功加载。
- 新增链接增加纵向高度 → 复用现有滚动容器，扩展既有尺寸和字体缩放检查。
- 模拟链接回调不能证明真实系统浏览器可启动 → 自动化检查与 Android、iOS、Windows、macOS、Linux 的实际打开验收分开记录，缺少环境的项目保持待验收。

## Migration Plan

仅涉及帮助地址、关于页链接行和相关测试，没有数据迁移。正式实施时运行相应检查；如需撤回，移除该入口及新增地址即可恢复既有页面。是否纳入版本发布另按用户指令处理。
